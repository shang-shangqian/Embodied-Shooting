# 模块目录

本目录用于组织实验代码。安装后按 `test_lk_ostrack`、`test11.speed_prediction`、
`integrated_shooting_chain`、`test7_2_weight` 导入；Isaac Lab SDK 另外安装。

| 文件夹 | 作用与入口 |
| --- | --- |
| [test_lk_ostrack/](test_lk_ostrack/README.md) | 视觉跟踪、采集和离线评估。 |
| [test11/](test11/README.md) | 速度估计模块。 |
| [integrated_shooting_chain/](integrated_shooting_chain/README.md) | 感知、速度、决策的联调、多目标控制和录像。 |
| [test7_2_weight/](test7_2_weight/README.md) | 决策网络训练和仿真评估。 |
